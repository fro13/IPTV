# История изменений

## 30 октября 2026 — интерфейс для телевизора

- При запуске открывается сетка всех 22 каналов в шесть столбцов, без автозапуска эфира.
- Сохранены тёмная тема, логотипы и номера; выбор пультом выделен синей рамкой.
- OK во время просмотра открывает список справа поверх видео; OK в списке включает выбранный канал и закрывает панель.
- Назад закрывает список без переключения; из просмотра возвращает к сетке.
- Компактная плашка канала скрывается через 3,5 секунды. Подсказок кнопок на экранах нет.
- Настройки буферизации поддерживают навигацию пультом. Интерфейс телефона сохранён.

## 30 октября 2026 — улучшения воспроизведения

1. **Настройка буферизации.** Три режима: быстрый (500 мс), сбалансированный (2000 мс) и устойчивый (4000 мс).
2. **Быстрое переключение каналов.** Меньше лишней инициализации LibVLC при смене канала.
3. **Автоматическое восстановление.** При зависании потока приложение пробует переподключиться к каналу.
