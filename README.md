### Примечание

**22 канала в разделе «Каналы оператора» работают только в сети ШПД МТС.** Для их просмотра устройство должно быть подключено к этой сети.

При использовании Wi-Fi необходима поддержка IGMP/multicast в локальной сети.

В отдельном разделе «Интернет-каналы» доступны **2×2, Animal Planet, BRIDGE, Dorama HD, TLC, Дом кино, Русский детектив, Кино ТВ, Суббота!, ТНТ4, Русский бестселлер, Дом кино Премиум, Ю, Большая Азия, Просвещение, История, Техно 24 и FUEL TV** через интернет-потоки HLS и HTTP. Для них нужен доступ в интернет; подключение к сети МТС и поддержка multicast не требуются. Доступность трансляции зависит от источника.
