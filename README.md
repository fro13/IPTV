### Примечание

**22 канала в разделе «Каналы оператора» работают только в сети ШПД МТС.** Для их просмотра устройство должно быть подключено к этой сети.

При использовании Wi-Fi необходима поддержка IGMP/multicast в локальной сети.

В отдельном разделе «Интернет-каналы» доступен **2×2** через HLS-поток Rutube. Для него нужен доступ в интернет; подключение к сети МТС и поддержка multicast не требуются. Доступность трансляции зависит от источника.
