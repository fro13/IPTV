# IPTV

Исходники приложения **МТС IPTV** для Android TV и телефона. 22 UDP multicast потока из плейлиста пользователя. Тёмный интерфейс, управление пультом и касаниями. 

### Сборка
На вкладке **Actions** откройте **Build Android APK**. После успешной сборки скачайте артефакт **IPTV-debug-APK** и установите `app-debug.apk` на телефон или TV.

**Примечание:** Multicast по Wi-Fi работает только при разрешении IGMP/multicast в сети. Интернет для IPTV не нужен, но устройство должно находиться в домашней сети.
